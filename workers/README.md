# Reusable worker profiles

These are public role charters and thought patterns. They are starting points,
not private memories. Copy them into a private worker store and add only the
context that the worker is authorized to retain.

- `project-manager.md` — decomposition, admission, coordination, and review.
- `hacker.md` — bounded implementation and technical verification.
- `writer.md` — clear, accurate, audience-aware communication.
- `scientist.md` — hypothesis, measurement, uncertainty, and audit.
