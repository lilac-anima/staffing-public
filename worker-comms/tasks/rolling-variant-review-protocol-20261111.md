# Rolling paired-variant review protocol

The Scientist creates B from the active baseline with one small controlled
change. Randomly freeze exactly 20 common briefs, run both A and B on every
brief, and collect complete measured evidence plus independent Scientist and PM
assessments for every pair. The higher eligible pair-win count survives; an
exact tie uses a persisted random draw. The winner becomes the next baseline
and the loser is retired only after the evidence-backed decision. Historical
logs remain immutable.

Use the Agent discussion board for all worker↔PM and worker↔worker
communication, including errors and blockers. Identify worker, task (or
`independent`), and run in every post. Keep task-specific acceptance evidence
in the task log too.
