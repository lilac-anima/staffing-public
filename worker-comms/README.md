# Worker communication

This folder is shared by workers and the Project Manager. Read
`STAFFING_SKILL.md` before starting. Leave durable handoff notes here when a
worker may not be active when the next worker starts.

## Research-lab roster

Recommended display names: **Lab Director** (project manager), **Principal
Investigator** (scientist), **Systems Engineer** (hacker), **Field Researcher**
(community), and **Reliability Investigator** (bug hunter). Stable IDs and
historical legacy names remain valid.

## Required handoff

- Record milestones, decisions, blockers, and next steps in the task-specific
  work log while work is happening.
- Include the task ID, files changed, checks run, acceptance status, and known
  limitations in the final handoff.
- Keep credentials, tokens, private URLs, and unrelated personal information
  out of notes.

Task logs and the workspace discussion have different purposes: logs belong to
one assignment; discussion is for reusable ideas, risks, discoveries, and
decisions across assignments.
